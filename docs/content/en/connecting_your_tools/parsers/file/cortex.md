DefectDojo accepts CSV vulnerability reports generated by Cortex XDR for host,
serverless, and image findings.

### Supported scan types

- Cortex Hosts
- Cortex Serverless
- Cortex Images

These reports use the same CSV field structure as Prisma reports. Cortex
custom tags are preserved on imported findings.
